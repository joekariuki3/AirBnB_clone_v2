# AirBnB clone — Static site

Pure HTML/CSS mockups for the AirBnB clone UI. Useful for styling and as a baseline for the dynamic Flask pages.

Contents:

- `*.html` — static pages by iteration
- `styles/` — CSS files per step
- `images/` — icons and logo

Quick preview: open any HTML file in your browser, e.g. `0-index.html`.

These assets are also packaged by the Fabric deploy scripts found at the project root.
